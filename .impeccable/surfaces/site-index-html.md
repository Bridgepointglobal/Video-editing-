## Direction contract

THESIS: Every sentence you say becomes one event in an edit decision list. The page is the EDL your conversation would print. It refuses the dark dev-tool hero with a neon gradient, terminal mock and feature-card grid.

OWN-WORLD: Continuous-form line-printer paper: white sheet with pale green bar banding, tractor-feed sprocket strips down both margins, perforation rules between sections. Monospace event rows (event no., reel, track, transition, four timecodes) with `*` comment lines. Ink: near-black carbon plus Resolve's marker colors as category flags. Display set in a heavy condensed grotesk, stamped like a report header.

STORY: Visitor reads the claim (works on Resolve Free), watches prompts print as numbered events with the real tool each one calls, understands the in-Resolve bridge, sees Free vs Studio honestly, copies the install, credits the author.

FIRST VIEWPORT: EDL header block (TITLE / FCM) top-left across the sheet; huge condensed headline "Talk to Resolve. Sprocket strips frame the viewport.

FORM: Edit decision list on green-bar printout; position 1 on my ordered list (the pick card); seed key 9ba25fb6.
