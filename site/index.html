    It runs inside Resolve, so Free is enough.

    Other Resolve MCP servers drive Resolve from outside, through external scripting, which Blackmagic locks to Studio. This one puts a small bridge script inside Resolve through the Scripts menu, which every edition has. The MCP server talks to that bridge over localhost.

    Running in four steps.

    DaVinci Resolve 18+ Free or Studio Python 3.9+ on the same machine An MCP assistant Cursor, Claude Desktop…

    1. Put the bridge script inside Resolve

      Copy src/CursorBridge.py into Resolve's scripts folder.

      ~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Utility/
      %APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Scripts\Utility\
      ~/.local/share/DaVinciResolve/Fusion/Scripts/

    2. Set up the MCP server

      * CMD · Terminal
      git clone https://github.com/hiteshK03/davinci-resolve-mcp.git
cd davinci-resolve-mcp
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt

    3. Tell your assistant about it

      Add this to .cursor/mcp.json, or your assistant's equivalent MCP config.

      * CMD · mcp.json
      {
  "mcpServers": {
    "davinci-resolve": {
      "command": "python",
      "args": ["path/to/davinci-resolve-mcp/src/resolve_mcp_bridge.py"]
    }
  }
}
      Cursor in WSL, Resolve on Windows
      * CMD · mcp.json for WSL
      {
  "mcpServers": {
    "davinci-resolve": {
      "command": "cmd.exe",
      "args": ["/c", "C:\\path\\to\\venv\\Scripts\\python.exe", "C:\\path\\to\\src\\resolve_mcp_bridge.py"]
    }
  }
}

    4. Start the bridge and talk

      Open Resolve and choose Workspace › Scripts › CursorBridge. When the console shows this line, your assistant is in control:

      Bridge is running (read + write)

    What it can't do yet.

    Most of these are limits of Resolve's scripting API and apply on Studio too. One is the cost of running AI on your CPU, and two are Studio-only features.

    • * NOTE:Keyframe animationThe API sets static property values only. Animate by hand.
    • * NOTE:Fusion node parametersText and effect values inside a composition still need the Fusion page.
    • * NOTE:TransitionsAdd them yourself from the Effects Library.
    • * NOTE:Background removal on videoIt runs on the CPU, so long clips take a while.
    • * NOTE:Gallery stillsResolve has to be on the Color page.
    • * NOTE:Smart Reframe and StabilizationStudio only, with no local replacement.
